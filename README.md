## 👋 Introduce
안녕하세요.  
**코드로 새로운 가치를 만들어가는 백엔드 개발자 박유찬입니다.**

단순히 기능을 구현하는 데서 그치지 않고,  
**왜 이 구조여야 하는지**, **운영 환경에서 어떤 문제가 생길 수 있는지**를 먼저 고민합니다.

Spring 기반의 백엔드 개발을 중심으로  
JPA · QueryDSL을 활용한 데이터 설계,  
Redis 기반 캐싱과 이벤트 처리,  
AWS · Docker · GitHub Actions · ArgoCD를 활용한 배포 자동화까지  
**개발부터 운영까지 이어지는 흐름**을 경험하며 성장하고 있습니다.
